# Imast — память проекта для Claude

Imast — Android-приложение «CRM для жизни» на основе стоицизма: дневник с утренними и вечерними вопросами, привычки, задачи, «Дни без» (воздержание), обучение с экзаменатором, наставники, прогресс, автопортрет, помощь по приложению. Автор — Марк, работает только с телефона.

## Как общаться
- Отвечать по-русски, коротко и честно, даже если правда неприятна. Если идея противоречит науке — сказать прямо и дать источник.
- Марк не видит файлы в рабочей папке: присылать ссылки, картинки и APK.
- Ключи API, пароли и токены никогда не попадают в код, коммиты или чат. Если Марк их присылает — попросить отозвать.

## Устройство
- `app/src/main/assets/index.html` — всё приложение в одном файле: HTML, CSS и JS. Хранилище — `localStorage` (`imast-demo-v1`), сервера нет.
- Строки интерфейса пишутся по-русски через `T_('...')`. `app/src/main/assets/en.js` — английские переводы, ключ = русская строка. Каждая новая строка интерфейса получает перевод.
- `app/src/main/assets/sw.js` — service worker «сначала сеть», чтобы приложение работало без интернета.
- `app/src/main/java/app/imast/` — Android-оболочка: `MainActivity` (WebView), `NativeBridge` (мост `window.ImastNative`: напоминания, шаги, виджет, `shareText`, `version` и др.), `QuoteWidget`, `Reminders`, `Steps`.
- Приложение сначала открывает онлайн-версию `https://armardi95.github.io/Imastapk/`, а без сети — встроенную копию. Поэтому правки index.html/en.js доходят до тестеров после публикации сайта, без нового APK. Новый APK нужен только для Java/манифеста; тогда поднять `versionCode` и `versionName` в `app/build.gradle`.

## Проверка перед коммитом
1. Синтаксис всех `<script>` (через `new Function`).
2. Playwright: русский и английский (`?lang=en`), пример данных (`[data-act="sample"]`), все разделы меню и изменённые окна.
3. Крупный системный шрифт: копия index.html, где все `font-size:Npx` умножены на 1.3 и 1.5; ширина 412 и 360 px. Текст не должен вылезать за рамки, страница не должна прокручиваться вбок. Пункты окон и меню не сжимаются (`.sheet>*,.drawer>*{flex-shrink:0}`), шапку и вкладки подгоняет `fitText()`.
4. Посмотреть скриншоты изменённых экранов глазами.

## Выпуск
1. Коммит с понятным русским описанием (что и зачем).
2. `git push origin main` → GitHub Actions: «Publish web version» (сайт) и «Build APK» (артефакт `imast-apk`).
3. `gh run list -R armardi95/Imastapk -L 4`. Если публикация сайта упала с ошибкой артефакта — запустить workflow заново через workflow_dispatch, а не rerun.
4. Проверить живой сайт: `curl` с `?v=<время>` и `grep` по новому коду.
5. Сказать Марку, нужен ли новый APK или достаточно перезапустить приложение с интернетом.

Keystore в репозитории — только для тестовых сборок. Для Google Play нужен отдельный секретный ключ вне репозитория.
